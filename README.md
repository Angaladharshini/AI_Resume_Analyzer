# AI Resume Analyzer

An AI-powered Resume Analyzer that helps users evaluate resumes and improve job application quality using machine learning and data analysis techniques.

## Features
- Resume upload and analysis
- Skill extraction from resumes
- Resume score prediction
- Job profile matching
- User-friendly interface

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- NLP

## Project Purpose
This project was developed to help students and job seekers analyze their resumes and identify areas for improvement for better career opportunities.

## Future Improvements
- ATS score analysis
- Multiple resume format support
- AI-based resume suggestions
- Real-time job recommendations
